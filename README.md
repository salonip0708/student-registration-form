# Student Registration Form Flutter App

A simple Flutter application that demonstrates how to create a **Student Registration Form** using **Form Validation**. Users can enter their details such as name, email, phone number, and password with proper input validation.

## Features
- Student registration form UI
- Name validation
- Email validation
- Mobile number validation
- Strong password validation
- Clean and beginner-friendly interface
- Submit button with form validation

## Technologies Used
- Flutter
- Dart
- Material Design Widgets

## Validation Rules

### Name
- Must contain at least 3 characters

### Email
- Must be in valid email format

### Phone Number
- Must contain exactly 10 digits

### Password
- Minimum 8 characters
- At least one uppercase letter
- At least one lowercase letter
- At least one number
- At least one special character

## How It Works
1. Enter Name
2. Enter Email Address
3. Enter Phone Number
4. Enter Password
5. Click **Submit**
6. If all fields are valid, form gets submitted successfully

## Project Structure
- `main.dart` → Contains complete UI and validation logic

## Output
The app checks all entered data and shows error messages if input is invalid.

## Use Cases
- Student registration system
- Login/Register form learning
- Flutter form validation practice
- Beginner Flutter projects

## Conclusion
This project is a beginner-friendly example to learn **Forms, TextFormField, Controllers, and Validation** in Flutter.
